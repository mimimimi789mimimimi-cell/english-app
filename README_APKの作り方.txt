# 中1英語マスター Androidアプリ（APKビルド用プロジェクト）

このフォルダをGitHubにアップロードすると、自動でAPKが作られます。

## 手順
1. GitHubで新しいリポジトリを作る（Privateでも可）
2. このZIPを展開し、中身（app、.github、build.gradle など）をすべてリポジトリにアップロードする
   ※ .github フォルダは隠しフォルダ。必ず一緒にアップロードすること
3. リポジトリの「Actions」タブ → 「Build APK」 → 「Run workflow」
4. 5分ほどで完了。実行結果の一番下「Artifacts」から EnglishApp-debug-apk をダウンロード
5. ZIPを展開すると app-debug.apk が入っている
6. APKをスマホに送り（Googleドライブ・USB・メールなど）、タップしてインストール
   （「提供元不明のアプリ」の許可を聞かれたら許可する）

## 仕様
- 通信不要。アプリ内にHTMLを同梱しているのでオフラインで動く
- 学習データはアプリ内に保存される（アンインストールすると消える）
- debug署名のAPK。個人利用向け（Playストア公開には不向き）
- この環境ではビルドの動作確認ができていません。Actionsでエラーが出たらログを教えてください
